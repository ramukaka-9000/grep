I'm sorry, but you still have to think

Piotr Sarnacki compares AI rewrites of Campfire Once in Rust and Elixir, showing how underspecified prompts silently choose different compatibility, concurrency, and failure policies. The benchmark dispute illustrates why throughput alone can hide notification loss and backpressure: under a reported 100 requests/second, one test measured only about 1% notification delivery for the Rust version before a buffer change, while larger buffers traded drops for very long latency. His point is not that one language wins, but that system constraints and what counts as failure still require deliberate engineering judgment.

500+ billion tokens later: letting AI agents decompile a first-person shooter

A months-long agent project made rapid visible progress—about 80% of the game decompiled in its first month—yet the resulting readable C++ was semantically wrong, with invented logic and costly architectural changes. The turning point was adding an objective oracle: compile reconstructed functions with the original compiler and compare their bytes against the original binary. The author estimates 600–700 billion tokens overall, but the durable lesson is that correctness criteria and independent verification beat apparent throughput.

RATED: retrieve tools using execution reliability, not relevance alone

RATED combines semantic matching with a lightweight contextual bandit that reranks tools using runtime success and failure feedback. On the authors’ EcoAgent benchmark of 5,172 tools and over 210,000 query-tool pairs, they report 52.2% relative MRR improvement over ToolLLM’s API retriever and a reduction in fault selection from 86.2% to 2.9% under a simulated 30% outage rate, with under 1 ms added latency. It is an author-reported benchmark result, but the design directly addresses the gap between finding a relevant tool and finding one that is currently usable.

ToFu fuzzes the trust boundary between LLMs, orchestrators, and tools

ToFu derives tool-specific semantic checks from metadata and a CWE-guided sanitizer corpus, then generates fuzzing harnesses and runtime oracles. The authors evaluated 3,405 tools across 273 MCP servers and report 253 verified semantic-security bugs in 118 servers, including cases where documented input constraints were not actually enforced. This is a substantial ecosystem audit, not evidence that every MCP server is unsafe; it reinforces that model-generated arguments must be treated as untrusted input.

Pensieve: local code search and MCP context for AI coding agents

Pensieve indexes files, Git repositories, and coding-agent sessions locally, then exposes scoped semantic and exact-text search through an MCP server. Its author reports 131 of 144 held-out file-finding runs succeeded versus 123 of 144 with grep alone, with fewer tool calls across four repositories; the benchmark scripts are available in the repository. It is useful when an agent needs a few relevant passages rather than broad, repeated filesystem searches, while the reported comparison remains author-run.

Anatomy is an agent skill that turns a technical concept into a small, working-object metaphor rendered as a detailed isometric figure, with SVG, optional WebGL shaders, and experimental 3D output. D1-600M-Text2SQL selects among supplied query candidates

This 587M-parameter FP32 model fine-tunes LiquidAI’s D1-Omni-600M to rank four SQL candidates from a schema, question, and fixed conversation history; the application supplies and executes the queries. Its model card reports 45.6% accuracy versus 24.9% for the base on 1,000 synthetic development turns, but the set was reused for model selection and option renaming changed predictions. It is a compact, narrow decision model—not a free-form SQL generator—and its custom code and permissions should be reviewed before use.

A 51.6M-parameter ACT policy fine-tuned for simulated basket handling

This 51.6M-parameter LeRobot ACT checkpoint targets the RoboSynChallenge simulated handle-basket task for a dual-arm robot with three RGB cameras and 14-dimensional joint state/action. A Nokia 3310 game jam entry gets a custom Pico PCB

Hoani built Trick Shot II for the Nokia 3310’s 94×48 monochrome display, buzzer, and keypad, then designed a custom PCB to fit the hardware into a gutted 3310 case. A Raspberry Pi Pico drives the original LCD and keypad, while the game engine is written in Go. The first board revision missed the case fit because it used 1.6 mm PCB instead of 1 mm, making this a concrete embedded-build story rather than just a retro-game demo.

A hex-cell grid improves a home-built PCB autorouter

James Bowman’s CuFlow autorouter uses Lee’s shortest-path algorithm on a hexagonal rather than square grid. Six equidistant neighbors avoid the unequal diagonal steps of square grids, and the denser cells can pack more traces into the same board area. The routing method is experimental and does not solve placement or high-speed signal-integrity constraints, but the geometry change is simple and reproducible.

60 Hz “hello” from a Metro RP2350

A Metro RP2350 with PSRAM runs CircuitPython 11 and outputs 640×480 video at 60 Hz through its 22-pin HSTX connection and an HSTX-to-DVI adapter. Arduino forum users KurtE and Merlin513 ported a ZephyrOS touchscreen weather application from the GIGA R1 WiFi to the much smaller UNO R4 WiFi. A thorium-229 optical nuclear clock with a feedback loop

Published October 7, the Nature team stabilized a continuous-wave laser to a 148 nm transition in thorium-229 nuclei embedded in a millimetre-scale calcium-fluoride crystal at room temperature. Feedback from the absorption signal lets the nuclear transition correct laser drift; the demonstrated clock’s fractional-frequency instability approaches 10⁻¹⁵ after a day of averaging. This is a first solid-state optical nuclear clock with promising stability, not yet a more accurate replacement for established clocks; the authors project substantial future improvements.

Birch tar made with prehistoric techniques inhibits wound-infection bacteria

A University of Cologne-led study recreated birch tar using techniques associated with Neanderthals and tested its antibacterial properties. The researchers report that every tested sample inhibited bacteria implicated in wound infections, making medicinal use a plausible hypothesis for a material already known as tool adhesive. Laboratory inhibition does not show that Neanderthals used it to treat wounds; the historical interpretation remains speculative.

Ice fishing for cosmic neutrinos

NASA’s October 11 Astronomy Picture of the Day features the IceCube Neutrino Observatory at the South Pole, which uses a cubic kilometre of Antarctic ice as a detector for high-energy neutrinos. The sensors watch for faint Cherenkov light from secondary charged particles produced when neutrinos interact in the ice. The image’s “fishing” metaphor is apt: neutrinos almost never interact, so the detector relies on immense instrumented volume and exceptionally dark, transparent ice.
