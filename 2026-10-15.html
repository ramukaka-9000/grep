OpenCode 2.0

OpenCode 2.0 turns the existing client/server design into a default local service: TUI, web, and desktop clients talk to one background process, and scripts can autodiscover it through @opencode/client. The API was rewritten around daily agent workflows, including moving a session into a git worktree when new work starts. Code Mode adds a minimal JavaScript interpreter that turns MCP servers and OpenAPI endpoints into callable functions so the model can script tools instead of issuing one tool call at a time.

pg_vectorsearch: an ANN index faster than pgvector IVFFlat and HNSW

Timescale's pg_vectorsearch is an alpha PostgreSQL extension for approximate nearest-neighbor search, with a PRISM index that uses hierarchical routing, RaBitQ quantization, and SIMD distance kernels. The authors say it is faster than pgvector's IVFFlat and HNSW at equivalent recall on a 100-million-vector set while using about a quarter of HNSW's memory, and it can index existing vector and halfvec columns. The project warns that upgrades between prereleases may require dropping and recreating indexes.

LFM2.5-24B-A2B: a 24B/2B-active model for on-device agents

Liquid AI released LFM2.5-24B-A2B on October 13, a 24B-parameter reasoning MoE with 2B active parameters, a 131K context window, and a 128K tokenizer. The company reports it matching or beating Qwen3.6-35B-A3B on five of eight agentic benchmarks, including 48.09 versus 38.19 on LiveClaw, and 184 tokens/s on an Apple M5 Max. Post-training used agent harnesses such as OpenClaw, Hermes Agent, Pi, and OpenCode; those scores and speed figures are vendor-reported.

Latent Compaction with Test-Time Training

Latent Compaction treats a document's KV cache as a small network and trains it at test time, without touching model weights or seeing downstream questions. The authors initialize cache entries from reconstruction importance, teacher attention, and key-space diversity, then distill the full cache into a compact one. On RULER they report 96.7% accuracy at 32× compression versus 40.0% for KVZip+, with code at THUNLP/latent-compaction; those numbers are paper-reported.

One Task, Many Interfaces: cross-interface consistency for LLM agents

This paper shows that post-training can glue an agent's skill to the names and notation of its tools: renaming actions or changing the interface leaves the task the same but can drop accuracy by nearly 25%. Cross-Interface Policy Regularization presents each sample under two interfaces with equivalent actions identified, then penalizes KL divergence between the resulting action distributions. In the authors' function-calling setup, CIPR recovers 10.5% of that drop without hurting the original interface.

Graphicle: local code graph and memory for coding agents

Graphicle is a local Rust program that builds a code graph of a repository, stores project docs and agent sessions, and serves cited excerpts over MCP to Claude Code, Codex, Cursor, and other clients. It needs no account or telemetry; graphicle setup indexes the repo, rewires agent search, and can be undone. A model is optional and used only for ask/memory extraction, including local OpenAI-compatible servers.

SteerTTS: a 9.6M-parameter TTS you steer with numbers

SteerTTS is a 9.59-million-parameter English TTS acoustic model that takes optional z-score controls for rate, loudness, pitch, pauses, and related acoustics, plus style tags, markup, and short-clip cloning. The model card reports CPU real-time factors of 4.9 without the flow refiner and 0.7 with it, and held-out steering hit rates near 1.0 for loudness and median pitch. Weights are CC BY-NC 4.0; the vocoder and optional refiner add parameters, and several controls such as CPPS are documented as weak.

embeddinggemma-2-ko: a small Korean retrieval fine-tune

This 0.7B EmbeddingGemma 2 fine-tune trains only the text transformer on Korean retrieval pairs, then interpolates back toward the base weights (α = 0.25) to keep image and audio retrieval. The author reports +0.009 average nDCG@10 on nine MTEB Korean retrieval tasks, with the largest gains on long-document and legal sets, and no check dropping more than about one point. It is a drop-in 768-d model with Matryoshka truncation; the card itself calls the gain modest.

UserRepGen-4B: a 4B model that writes user representations, not fake turns

Microsoft's UserRepGen-4B is a LoRA fine-tune of Qwen3.5-4B that writes a JSON task description and user-behavior sketch from a multi-turn chat, for conditioning a separate user simulator rather than emitting fake user turns. The 4B-class checkpoint is MIT-licensed; the card lists about 9.1 GB of weights and a CPU smoke test, so 4-bit quantization is the realistic 3060/3070 path. Behavior descriptions improved a same-user re-identification check to 51% versus 25% random, which the authors flag as a privacy risk, not an anonymization feature.

Using an ESP32-C3’s RF Hardware for DVB-S2 Video Transmission

SP8ESA's ESP32-DATV project uses the ESP32-C3's 2.4 GHz radio path to emit a DVB-S2-formatted stream, with a host PC packing the video and the microcontroller preparing samples for the RF block. No extra transmitter hardware is required, but the chip cannot reach the 10.7–12.7 GHz satellite downlink band, so a stock DVB-S2 set-top box will not see it. It extends the recent wave of undocumented ESP32 I/Q hacks; transmit experiments need a license and a dummy load.

Marshall Islands stick charts mapped swells, not coastlines

Marshallese stick charts mapped ocean swells, not coastlines: coconut-frond midribs and shells encoded how islands bent rilib, kaelib, and other swell trains. Navigators memorized a chart before launching and then felt the canoe's pitch rather than consulting it at sea. Use faded after World War II as electronics, fewer canoe voyages, and nuclear testing disrupted the practice; each chart was often readable only by its maker.

Scientists are teaching birds to sing lost songs

Researchers in Buenos Aires synthesized a rufous-collared sparrow song from the 1960s that had vanished locally; within three months a wild bird began copying parts of it, according to work featured by The Guardian and Yale Environment 360 on October 14, 2026. Co-author Gabriel B. Mindlin frames learned song as cultural biodiversity that shrinks when populations crash. The sparrow is not globally threatened; the hope is that synthetic tutors could help rarer songbirds when no living tutor remains.

Mars moon lander set to launch on 19 October

JAXA's Martian Moons eXploration mission is scheduled to lift off on an H3 from Tanegashima at 04:41 JST on 20 October 2026 (19 October in Europe), aiming to return the first sample from Phobos. ESA, NASA, CNES, and DLR are partners; after a quasi-satellite orbit the craft will deploy the 25 kg Idefix rover, land, sample, and fly past Deimos on the way home. Whether Mars's moons are captured asteroids or impact debris is the open question the sample is meant to settle.

NASA’s Chandra Breaks Down ‘Treble Clef’s’ Galaxy Cluster Collision

Chandra and eROSITA X-ray maps show that a radio shape nicknamed the Treble Clef sits in two merging galaxy clusters almost behind the Milky Way's disk. Andrea Botteon and colleagues argue in Astronomy & Astrophysics that an earlier supermassive-black-hole outburst inflated a fading radio cloud, then the cluster collision reenergized it. The 14 October 2026 NASA write-up composites Chandra/eROSITA X-rays, LOFAR radio, and UKIRT infrared.

The Einstein–Szilárd refrigerator had no moving parts

In 1926–1930 Einstein and Leó Szilárd patented an absorption refrigerator with no moving parts, driven only by heat, using water, ammonia, and butane. They were reacting to deaths from leaking toxic compressor seals; Electrolux bought key patents, but Freon and the Depression kept the design off most kitchen floors. A related Einstein–Szilárd electromagnetic pump later found a life cooling breeder reactors, where no-moving-parts reliability mattered.
